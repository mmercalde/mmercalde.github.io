Privacy policy: copytrader-rclone

Last updated: 2026-10-06

  • Who uses it: only its owner. It is a personal tool, not a public service.
  • What it accesses: it uses the Google Drive drive.file scope, so it can only see and change the files it created itself. It cannot read any other file in the Drive.
  • What it collects: nothing from anyone else. It uploads the owner's own report files to the owner's own Drive, and it does not share data with anyone.
  • Contact: through the owner's GitHub profile, github.com/mmercalde.
